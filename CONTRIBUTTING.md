# Contributing to Solara Browser

We appreciate your interest in contributing to Solara Browser. Please follow these guidelines.

## Code of Conduct

By participating, you agree to abide by our Code of Conduct. See CODE_OF_CONDUCT.md.

## How to Contribute

1. Fork the repository.
2. Create a feature branch (git checkout -b feature/your-feature).
3. Make your changes.
4. Run the linter (./gradlew ktlintCheck) and tests (./gradlew test).
5. Commit with a clear message.
6. Push to your fork and open a pull request to the main branch.

## Pull Request Guidelines

- Keep changes focused and atomic.
- Update documentation if needed.
- Ensure the CI passes.
- Wait for review.

## Reporting Issues

Use the GitHub issue tracker. Provide as much detail as possible, including steps to reproduce, expected and actual behavior, and version.

## Development Setup

- Install Android Studio.
- Clone the repository.
- Open the android/ folder as a project.
- Build and run.

## Style Guide

- Kotlin: follow official Kotlin coding conventions.
- Use Ktlint for formatting.
- Write clear commit messages.
