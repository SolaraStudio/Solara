# Solara Browser

## A browser that feels like light.

Solara is a minimal Android browser with a glass‑morphism interface, vertical tabs, and a clean focus on browsing.

## What makes it different

- Flowing glass UI with live blur
- Vertical tabs that slide in from the edge
- Material You dynamic color
- Built for speed, not bloat

## Tech stack

- Kotlin + Jetpack Compose 
- Material 3
- Gradle (Kotlin DSL)

## One‑line build

```
cd android && ./gradlew assembleRelease
```
